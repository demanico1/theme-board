# theme-board

테마 달력 뷰어가 내려받는 **데이터 저장소**입니다. 코드는 없습니다.

- 실제 데이터는 **Releases** 탭의 `latest` 릴리스 자산에 있습니다.
- 자산은 **암호화**되어 있습니다 (PBKDF2-HMAC-SHA256 200,000회 + AES-256-GCM).
  암호를 모르면 내용을 볼 수 없습니다.
- `latest.json` 만 평문이며, 지문·크기·발행 시각만 들어 있습니다.
  뷰어가 **받기 전에** 새 것인지 판단하기 위한 것입니다.

매일 자산 하나를 **덮어씁니다.** 쌓이지 않으므로 용량이 늘지 않습니다.
